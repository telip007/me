Was eine gute technische Erklärung leisten muss

Eine konkrete Frage, ein nachvollziehbares Beispiel und die Belege, die die Antwort tragen.

In diesem TextDie Frage eingrenzenDas Beispiel wählenBelege sichtbar machen

Eine technische Erklärung hilft, wenn nach dem Lesen eine konkrete Entscheidung leichter fällt. Dafür muss sie ihren Gegenstand benennen und zeigen, unter welchen Bedingungen ihre Antwort gilt.

Die Frage eingrenzen

Der Einstieg liefert die entscheidende Erkenntnis. Was soll die Software tun? Welches Verhalten überrascht? Welche Beobachtung ändert die nächste Entscheidung?

Das Beispiel wählen

Ein kleines Beispiel ist nützlich, wenn es den entscheidenden Zusammenhang erhält. Code bleibt als Text lesbar; die Erklärung benennt, worauf es ankommt.

def explain(question, evidence):
    return {
        "answer": question.resolve(evidence),
        "limits": evidence.conditions,
    }

Belege sichtbar machen

Quellen stehen dort, wo sie eine Aussage tragen. Ein beobachtetes Ergebnis und eine daraus abgeleitete Vermutung sind unterschiedliche Dinge. Die Gestaltung hält beides lesbar und auffindbar.

Diese Seite zeigt eine mögliche Gestaltung. Sie behauptet keinen durchgeführten Versuch und enthält keinen neuen veröffentlichten Blogbeitrag.
