# Visual direction studies — 29 October 2026

The first blue/white design was rejected. These code prototypes explore three replacement systems; A was explicitly selected by the user; B and C remain unselected. Open index.html through a local HTTP server for the comparison, then a.html, b.html or c.html for full home/reading treatments. The article text is an explicitly labeled layout sample, never a source post.

Research: ../research/expressive-design.md, ../research/brand-character.md, ../research/geist-system.md plus original independent sources below. The first implementation's accessibility/backend evidence remains useful, but does not validate the rejected visual direction.

Broader original references examined by root: [Distill](https://distill.pub/), [Ink & Switch](https://www.inkandswitch.com/), [Pentagram MIT Media Lab](https://www.pentagram.com/work/mit-media-lab), [Bartosz Ciechanowski](https://ciechanow.ski/), [Maggie Appleton](https://maggieappleton.com/). Distill and Ciechanowski demonstrate explanation through interaction; Ink & Switch ties medium to subject; Maggie's structure follows her actual body of work. These support editorial/interaction principles, not a copied aesthetic or a reason to fabricate an article archive.

Fonts: Bricolage Grotesque, Fraunces and Instrument Serif from https://github.com/google/fonts/tree/main/ofl/ (their corresponding family directories). Local WOFF2 conversions/subsets U+0000–024F; original OFL licenses included. No third-party font request. Original geometry and CSS. The selected A system is being integrated into production templates/styles; the other fonts and studies remain outside public assets.

Desktop and390px prototype screenshots were inspected in a bounded pass. An intrinsic-width overflow in the reading sample was fixed; all three now report no page overflow at390px. This is concept verification, not production acceptance or a full accessibility audit.
